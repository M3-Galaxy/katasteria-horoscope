# Katasteria — 逆引きホロスコープ

> **星の配置（サイン・アスペクト）から該当日時を逆引き探索する、Web完結型のネイタルチャート探索・鑑定シート作成ツール**

1200年〜2100年（約900年間）の膨大な天体データから、指定した天体のサイン配置やアスペクトを満たす日時をノーウェイトで高速検索します。

---

## 🌟 主な機能

* **超高速な逆引き探索エンジン**
  * 1200〜2100年（3つの時代チャンク）の事前計算テーブルを用いた区間交差演算により、瞬時に候補日時を抽出。
  * 天文学的にあり得ない組み合わせを事前に防ぐリアルタイム条件バリデーション（残数カウント表示）。
* **メジャーアスペクト逆引き**
  * 合（0°）、オポジション（180°）、トライン（120°）、スクエア（90°）、セクスタイル（60°）の配置条件指定に対応。
* **インタラクティブなホロスコープ円図**
  * ASC左固定の世界標準レイアウト、12ハウスカスプ線、天体シンボル、アスペクト線をSVGで精密描画。
  * スライダー操作に追従して60fpsで滑らかに回転するリアルタイム微調整。
  * プラシーダス方式 / イコールハウス方式の切り替え対応。
  * 国内主要10都市（札幌〜那覇）の観測地プリセット。
* **アスペクト表（階段状三角マトリクス）**
  * 10天体同士の合・調和・緊張アスペクトをリアルタイム表示。
* **鑑定シート作成 & 高解像度PNG保存**
  * チャート・天体度数・サビアンシンボル詩行・解釈メモを統合したカルテ風カードを生成。
  * 2つの美しい世界観テーマ：
    * 📜 **黄昏の羊皮紙（Parchment）**：洋古書風アンティークデザイン
    * ✨ **宵の明星（Hesperus）**：深遠な群青と星屑のアイスブルー
  * 2倍解像度（Retina対応）でのワンクリックPNG保存（SNSシェア・創作設定資料向け）。

## 🛠 技術構成

* **フロントエンド**: HTML5 / Vanilla CSS / Vanilla JavaScript（ノービルド・完全静的構成）
* **天体位置計算**: [Astronomy Engine](https://github.com/cosinekitty/astronomy)（ブラウザ同梱）
* **画像エクスポート**: [html2canvas](https://html2canvas.hertzen.com/)（Retina対応）
* **フォント**: Google Fonts（Cardo, DM Mono, Shippori Mincho, Kiwi Maru, Noto Sans JP 他）

## 🚀 使い方

静的ホスティング（GitHub Pages 等）またはローカルサーバー（Live Server, `npx serve .` 等）ですぐに動作します。

```bash
# 依存ライブラリのインストール（データ生成ツール用）
npm install

# 開発用ローカルサーバーの起動例
npx serve .
```

ブラウザで `index.html` を開くだけで全機能をご利用いただけます。
